# 先懂再深入：本项目的备课方法

适用于新课和用户反馈“看不懂”的存量课改版。目标是让用户先形成一个能解释现象的模型，再愿意深入；采用 MOS 小灯入门课已获用户认可的讲解顺序，具体场景、媒体数量和时长按学科调整。

## 先决定教什么

写正文前确定三个问题：用户已经认识什么；这次只想让他解释什么现象；第一次学完能独立说清哪两三件事。删去完成这三个出口不需要的前置概念，将它们放到选学。不要把“完整覆盖知识清单”当成基础课的目标。

选一个熟悉对象贯穿。例如 MOS 用同一盏灯，高斯溅射用同一个杯子，贝叶斯用同一批灯，语音工作流用同一小段旁白。中途换领域或数字会增加额外负担；换场景放到最后的迁移题，并明确哪些条件变了。

## 默认的讲解顺序

| 学员此刻的问题 | 教材怎样回答 | 常见跳步 |
| --- | --- | --- |
| 这是什么？ | 用一句日常语言说明对象及作用，真实名称放在附近 | 从缩写、公式、项目架构图开始 |
| 我在哪里会遇到？为什么要它？ | 给出熟悉用途，再展示没有它时的具体困难 | 罗列很多应用，却没有一个正常例子 |
| 哪几个东西在起作用？ | 先命名角色和输入输出；具体元件可先认外形，抽象概念先认场景 | 为所有概念硬套“长什么样” |
| 它怎样解决问题？ | 沿同一个例子逐步解释：改变什么 → 发生什么 → 为什么 | 只写结论，要求用户自行补中间因果 |
| 我能不能试一下？ | 先预测，只改一个条件，再观察；基础操作约 3～5 分钟 | 一开始就要求安装大环境、算多个公式 |
| 哪一点容易用错？ | 只补最相关的一条边界，再邀请用自己的话解释 | 一口气堆全套例外，打断刚形成的直觉 |

顺序服务于理解，不要求每课做成同一模板或恰好五张图。基础路径通常约 8～15 分钟；给深入者保留 15～30 分钟的实验和源码支线。

## 写出可以听懂的解释

首次出现新词，紧接一句“这里就是……”。例如“负载，就是用电的小灯”；“共地，就是开发板的地端也接到 S 这一侧”。第一次用“拉回 S 电位”时，应接着解释“让 G 与 S 的电压差接近零”。后文才用简称，不能在基础答案里突然引入未解释的 GPIO、似然或 token。

类比先写清各角色的对应关系，再回到真实机制，并说清最容易误用的地方。水龙头的手柄对应控制端，水源对应外部电源；不能暗示控制信号给灯供能。解释应通俗且准确，不把“电压控制”写成任意 3.3V 都适用，也不把拔掉控制线说成可靠关断。

用完整短句补因果，不能为缩字数删掉关键步骤。比如把“后验=真报警/总报警”先讲成“既然已经知道它报警了，我们只留下报警的产品；这组里面有真报警，也有正常件误报。再数其中多少真坏”。公式最后作为压缩表达。

配音要能脱离屏幕理解：说出对象、动作、变化与理由，少说“这个、那里、如图”。主讲和源码深讲分开；需要观察或操作时明确提示暂停。温柔女声和原创学院画风用于引导注意，不能替代解释。

## 图、声音、练习必须教同一件事

为每个步骤检查“图中的变化—正文解释—旁白—下一道问题”是否一致。图解刚教谁供能，就先问供能来源；不要突然考电压差、手册选型或热计算。先给一个正常例子，再用只改变一个条件的问题检验迁移。

一图一件事，稳定颜色配合文字和符号表示角色。数字或面积用于计数时须有明确单位，画面不能偷偷换单位；元件运动符号须区分电子、约定电流与电场。实际操作手机页面核对图片切换；不能因案例和图解步数相同，就假设界面自动配图。当前案例组件固定显示 capture 或第一幅图，分步图在“看懂原理”标签中切换。仅更新课程时，要标明每步对应图的位置，不能宣称案例配图联动；修改运行组件则另走 APK 发布。

修改主路线后，逐项核对短视频、主章语音、整课列表、源码旁白、图解题、实验入口及回想题。准确且仍匹配的媒体可以复用；需要改的媒体先实际生成、完整解码和测量，再换字段。不能让新正文继续默认播放旧版高密度讲解，也不能只改旧音频标题冒充新内容。

基础出口只要求能解释本课的两三件核心事实，再给一题变化条件的预测。计算、参数选择、例外情况和完整代码可标“进阶选学，第一遍可跳过”。旧回忆题的 ID 与知识目标保留；新增基础题用新 ID，不能用简单题冒名替换原计算题。旧 App 只会显示文字标签时，就明确这是阅读提示，不能宣称自动分层或自动调整复习计划。

## 改版后的验收

在约 298px 的实际图宽检查关键标签，在手机布局检查案例、实验和进阶入口。核对旁白文本与音频元数据，完整解码、测量时长，再实际操作播放、暂停和章节跳转。整课在实验、应用、总结前的教学暂停要有清楚提示，与媒体出错区别对待。

最终由用户闭卷解释一条因果链，并换一个条件预测结果。观看次数、生成课件、助手跑通实验、用户说“看起来还行”，都不能作为掌握记录或学习提速数据。改版报告说明已验证的内容与尚待手机体验的部分，避免保证“十分钟就学会”。

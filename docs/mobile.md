# 手机网页与静态部署

本页说明浏览器与主屏幕网页版本。安卓手机优先使用 [APK 版本](android.md)，它支持确认后直接写入日历和在 App 中从公开 GitHub 更新课程。

手机网页包含已制作课程、图解、音频、练习和回忆题，不需要一直连接电脑服务，也不在手机上自动生成课程。

## 构建和预览

在项目根目录使用 Python 3.9+：

```sh
python3 learning_loop.py doctor
python3 scripts/build_site.py --output dist/site
```

产物在 `dist/site`，只包含登记课程、引用媒体、公开实验、来源许可和运行文件，不读取私人数据库。使用项目现有本地服务预览：

```sh
python3 learning_loop.py serve
```

打开 <http://127.0.0.1:8765/mobile/>。这只指向当前电脑；手机的 `127.0.0.1` 指手机自己，正式手机使用应打开部署后的 HTTPS 地址。

## GitHub Pages

1. 将公开项目放入自己的 GitHub 仓库，确认没有私人数据与机器路径。
2. 仓库 **Settings → Pages → Build and deployment** 将 Source 设为 **GitHub Actions**。
3. `.github/workflows/pages.yml` 在 `main` 分支相关内容变化时构建，也能在 Actions 中手动运行 **Publish mobile courses**。使用其他默认分支时调整工作流。
4. 构建与部署成功后，打开 Pages 设置或部署记录给出的真实网址。常见形式为 `https://用户名.github.io/仓库名/`，以自己的部署结果为准。

资源按部署目录解析，支持仓库子路径。也可将同一目录交给其他 HTTPS 静态托管，无需模型 API key 或数据库。

## 安装与离线

iPhone 在 Safari 分享菜单选择“添加到主屏幕”；Android 使用浏览器“安装应用 / 添加到主屏幕”。支持安装事件时页面会提供按钮。

第一次联网打开后保持页面开启，等顶部显示“已保存离线课程”。已缓存图解、音频与练习之后可离线使用，新课需联网更新。清理站点数据、隐私模式和设备空间限制可能影响保留，需定期备份。安装不等于启用云同步或推送。音频由用户主动播放，系统可能在后台暂停。

## 记录与备份

学习档案在当前浏览器 localStorage。不同浏览器、站点地址、设备、安卓版 WebView 与电脑 SQLite 独立。

设置里“导出学习记录”保存手机 JSON。换设备后选择该备份，先验证课程、问题和记录关联，确认后整体替换本机记录，不合并、不上传。建议先导出当前记录。电脑端 JSON 与手机格式不同，不能直接互换。

若旧档案中的课程或问题在当前课库缺失，保留原始数据，先导出再恢复匹配课库；不要清空记录。维护者须保留课程与问题 ID。

## 提醒与更新

打开应用时显示到期复习。可在设置导出每天 20:00 的日历，再自行导入手机日历，提醒由日历与系统设置决定。这是每日复习时段，不会随每张卡到期时间自动调整，导出文件本身不代表已经设置成功。

网页版本没有关闭网页后的推送、云同步或云端备课。安卓版可以在每次确认、授权并选择可写日历后直接设置每日安排，系统日历负责提醒；这不等于云端备课。需要定期发现与备课时，在电脑端配置学习助手和调度器。

新增课件后重建部署，手机联网检查更新。课程和媒体按完整版本更新，避免新文字配旧声音。更新不应清除学习记录；删除课程或改变问题 ID 会影响旧档案匹配。

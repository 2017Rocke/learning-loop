# 星灯学院体验

星灯学院为已有课程增加原创的探索地图和任务入口。轻羊皮纸、翡翠绿、黄铜金与彩色浮岛用于导航；原来的技术图解、视频、晓晓语音、逐行源码说明和学习记录继续承担教学。幻想插画是场景隐喻，不作为电路、概率或渲染原理的证据。

## 探索与学习

- 学院首页：先选一个问题；已有个人探索时，依据自己的实验、应用、总结记录提示下一步。到期复习有独立入口。
- 探索页：地图地点对应高斯溅射、贝叶斯、VoiceStudio、电容、MOS 管五个主题；课程书架支持全部课程、学科筛选与搜索。没有地图插画的新课程仍可从书架进入，不需改 APK 才能显示基础内容。
- 课堂：每节有一个目标，原理视频优先呈现，整课听讲、单章音频、图解预测和深入资料保持可用。所有章节自由进入，没有强制解锁。
- 记录：只展示已有实验、应用和总结记录。选地图、看片、听讲、试玩或作答一次，均不会自动写为掌握。

界面配置在 `web/mobile/academy.js`，样式在 `web/mobile/academy.css`，七张静态原创 SVG 在 `web/mobile/academy/`。地图根据 `topic_id` 选取地点，课程实际路由仍使用原有 `course.id`；未配置主题使用通用封面。所有标题和课程内容仍由安全 DOM 文本节点呈现。

## 电容接力工坊

入口为电容课程的「动手实验」，页面在 `web/lab/capacitor/index.html`。学习者先选预测（也可选不确定），再调整电容量、额外电流与脉冲时长，显式开始、暂停或直接看结果；时间拨盘支持逐段观察。可以保留一条灰色对照曲线，只改容量重跑；改变负载条件会清除对照，避免把不同条件混为一谈。迁移题的解释在选择后显示。

这是一组理想教学数据，不是开发板实测。初始 3.3 V，负载基流 40 mA；电源电流以固定 40 μs 时间常数跟随负载，电压由 `C dV/dt = I电源 − I负载` 得到。负载增加时电容补缺口，负载下降后电源剩余电流回充。示例 3.0 V 下限不等于电容完全放空。模型忽略 ESR、ESL、漏电、真实稳压器的电压反馈等，不能直接作为选型依据。

电路只画**约定电流方向**，引线箭头不跨越极板之间的绝缘层。电压、电流曲线与文字读数同步显示；允许减少动态效果，动画离开前台时暂停。约几百微秒过程放慢到九秒显示，真实模拟时间另行标注。实验不读写学习档案，返回课堂后由学习者记录自己的观察。

## MOS 管机械开关工坊

入口为 MOS 管课程的「动手实验」，页面在 `web/lab/mosfet/index.html`。学习者比较关断、持续导通与 PWM，观察栅极信号和负载回路的区别。教学电源为 5 V，负载为 10 Ω 纯电阻，假设所选管在 3.3 V 栅源电压时充分导通、导通电阻为 0.1 Ω。导通时电流为 `5 / (10 + 0.1)` A；平均负载功率为占空比乘以导通瞬时负载功率。

模型忽略开关过渡、栅电荷、寄生参数与温升。它不能预测电机速度或感性负载的关断波形，也不能用阈值电压推断充分导通。页面不存学习记录；返回课堂后由学习者自己保存观察。

## 部署与验证

静态构建会复制并预缓存 `web/mobile/` 与 `web/lab/` 下的运行资源。新版 App 必须随 APK 打包这些文件。远程课程 ZIP 仍只包含课程 JSON 与媒体，不包含脚本；旧 APK 拉取课程不能获得地图或新工坊。发布前仍需递增 APK 版本、验证签名与完整构建，本文不代表已发布。

Android 仅精确放行 `lab/capacitor/index.html` 与 `lab/mosfet/index.html` 这两个新增顶层页面。实验室不能取得日历、备份等原生桥；主页路径、包名与学习档案键不变。已保存记录继续使用原验证流程，浏览器与手机也不会自动互相同步。进入独立实验前会检查所有未保存的记录或复习草稿，并回到对应章节让用户处理；不会自动保存。浏览器从页面缓存返回时重建播放器，仍由用户主动播放。

执行既有 Python、移动端与离线测试；电容电荷守恒、容量比较和回充测试已接入 `node tests/test_mobile.js`。`scripts/check_android.py` 包括精确文档导航与仅主页桥接规则的独立检查。仍须用浏览器验证窄屏布局、地图选择、搜索、视频播放与清理、工坊参数对比和返回；手机真机验证不能用网页结果代替。

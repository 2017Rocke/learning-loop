# 四门存量课程的入门改版

## 改版目标

沿用 MOS 入门课得到的用户反馈：先理解是什么与用途，再沿一个熟悉案例追踪因果，做一次单条件预测，最后进入进阶选学。可复用方法已写入 [beginner-first](../../skill/learning-loop/references/beginner-first.md)，由 skill 主入口与教学包规范链接。

| 课程 | 基础路径 | 保留的深入材料 |
| --- | --- | --- |
| Brush / 高斯溅射 | 一个静止杯子，从不同位置拍照 → 三维软色斑 → 投影画图 → 比较调整 → 新视角 | 固定 commit 的连续源码、逐行旁注、训练与渲染边界 |
| 贝叶斯 | 同100盏灯，10故障90正常 → 8真报警9误报 → 在17盏里重新数 | 原10,000件产品实验与计算题，明确为另一组进阶数据 |
| VoiceStudio | 同三句复习提醒，分清工作台和模型 → 文字声音配对 → 按序拼接 → 对稿试听 | 分块边界、空块处理、交叉淡化源码与对应深听 |
| 电容与去耦 | 芯片电源旁的小元件 → 临时储能类比 → 突然忙 → 电源接力 → 需求回落与回充 | 容量计算、有效电容量、ESR/ESL与布局 |

每门课更新五幅因果图、机制视频及主章配音。五幅是本次例子的选择，不是后续备课的硬模板。声音使用晓晓合成中文女声，视频、主章听讲、图解与案例保持同一条线。公式和特殊情况用明确的“进阶选学”提示；现有 App 不据此自动分层或改变复习日程。

## 事实与媒体核对

- Brush 本轮读取固定提交 `1388f74c` 开头的官方 README 与核心实现；完整提交与原文位置在课程来源中。视频的杯把调整只演示单参数图像误差反馈，不冒充 Brush 实际训练，也不把外观重建说成精密网格或可直接打印模型。
- VoiceStudio 本轮读取固定提交 `7703ca66da77b8d130e6d1d3b2e67d979fa5a77f` 的 README、分块/拼接源码与音频质量文档。空段拼接不会自动补句，波形与卡片是教学示意。
- 贝叶斯核对 Stanford 教材的条件方向和全概率分母。100盏灯是合成例子，每点始终一盏；画面不会改真实类别。迁移题先预测，答案放反馈。原大样本题的 ID 与答案保留。
- 电容核对 OpenStax、TI 与 Murata 的结构、充放电、短时去耦和有效容量资料。动画没有电子穿过绝缘层；运动符号明确为约定电流，电源持续供能，电容只提供暂时差额。

新视频实测时长分别为 Brush 81.800秒、贝叶斯98.267秒、VoiceStudio98.000秒、电容118.867秒。全部完整解码并检查非静音、字幕窗口和298px图宽；贝叶斯计数阶段1208帧检查数量与类别不变，电容对图及动画执行15250次箭头边界检查。字幕为按句长分配的时间窗，不声称词级对齐。

## 兼容性与验收

四课原30个复习问题ID及答案保留，另加11个基础问题；课程ID和真实源码片段保持稳定。导入本地已有四条主线后，主线状态、实操证据、复习事件和已学主题未改变。当前本地档案原无复习卡，导入后仍无卡；不能把此结果说成在有卡真机上完成了升级测试。现有记录与更新隔离行为另有自动化测试覆盖。

本轮已通过86项Python测试、41项前端测试与Service Worker检查，静态站点及Android纯内容包构建通过。没有更换App运行代码，本次通过课程更新交付，无须新APK。学习者的手机实际播放与理解效果仍需体验；媒体可播和结构校验不等于已掌握，也不证明学习速度提升。

旧版案例页固定显示第一幅认对象图，点击案例步骤不会换图。本轮浏览器检查确认这一限制，四课已在案例步骤标注对应原理图位置；完整五图在“看懂原理”页切换。本次内容更新不宣称增加了案例图片联动。

## 后续判断是否有效

先请学习者闭卷用自己的话说明一条因果链，再只改变一个条件预测。若仍卡住，记录具体跳步、新词或图中不明角色，针对那一点修订。不要把听完、点击次数、助手验证或“看起来还行”作为掌握记录。
